# Click Counter

A simple, interactive click counter built with HTML, CSS, and JavaScript.

## Features

- Increment the counter with a click
- Decrement the counter with a click
- Reset the counter back to zero
- Clean and minimal UI
- Lightweight — no frameworks or dependencies

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/Charlostar123/Click-counter.git
```
2. Open `index.html` in your browser — no build step needed.

## Project Structure
```
Click-counter/
├── index.html   # App markup
├── style.css    # Styles
└── index.js     # Counter logic
```
